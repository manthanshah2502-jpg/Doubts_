# Doubt Tracker — Real Android App

This project builds an actual Android APK. It is NOT dependent on GitHub Pages.

Features:
- Physics, Chemistry and Mathematics columns
- Add unlimited doubts
- Tick doubts as completed
- Delete doubts
- Choose a photo from the phone Gallery
- Take a new photo with the camera
- Crop the photo before saving
- Tap any saved photo to open it larger
- Local persistent storage
- Works offline after installation

## Build with GitHub Actions
1. Create a new GitHub repository.
2. Upload EVERYTHING in this folder, including the hidden `.github` folder.
3. Push to the `main` branch.
4. Open GitHub -> your repository -> Actions.
5. Select "Build Doubt Tracker APK".
6. Open the completed workflow run.
7. Scroll to Artifacts and download "DoubtTracker-APK".
8. Extract it and install `app-debug.apk` on your Android phone.

This is a debug APK for personal use. Android may ask you to allow installation from your browser/file manager.
